# Security reporting

Report vulnerabilities through **Report a vulnerability** on the [repository's Security Advisories page](https://github.com/weber-stephen/Runsplice/security/advisories). Do not include captured content, credentials, or personal data in a public issue.

Captured content can retain unexpected sensitive values. Treat every `.agentdbg` store as private and review it before sharing. The Docker worker limits accidental effects; it is not a hostile-code sandbox. Windows storage ACL protection has not been verified.
